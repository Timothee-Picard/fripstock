# Archive des prompts

Ces fichiers sont les prompts qui ont servi à **construire** l'application, un par
lot de travail, dans l'ordre de leur numérotation.

Ils décrivent une intention à un instant donné, pas l'état actuel du code. Ils citent
des noms de champs en français (`estVente`, `notifieLe`, `/produits/export`) d'avant la
traduction du code en anglais, et des découpages de permissions qui ont changé depuis.

**Ne pas les lire comme une spécification.** Ce qui fait foi :

- `CLAUDE.md` — règles métier et conventions
- `README.md` — comment l'application fonctionne, et pourquoi
- `.claude/memoire/` — où aller chercher quoi

Leur intérêt est de retrouver le _pourquoi_ d'origine d'une décision, quand le code seul
ne le dit pas.
